## 什么时候写一份新的

取舍值得写下来的判据只有一条:**将来有人会重新提出被否掉的那个方案。** 会,就写;不会,写在代码注释里就够了。

写法照抄现有任意一份:标题 `# ADR NNNN — 主题`、状态行(含日期)、背景、决策、被否方案与理由。编号顺延,不复用。
